Ce contrôle ne transmet aucune donnée. Il vérifie les fonctions nécessaires pour utiliser le diagnostic, les audios et le mode hors ligne.

Que faire si un test échoue ?

Actualise la page avec Ctrl + Shift + R, puis relance le contrôle. Pour l'audio, vérifie aussi que ton navigateur dispose d'une voix anglaise et que le son de l'appareil est activé.
